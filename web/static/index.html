使用说明

Docker Hub 代理（推荐 daemon.json 方式）：

1. 创建类型为 docker 的链接

2. 编辑 /etc/docker/daemon.json：

{
  "registry-mirrors": ["https://yourdomain.com/{linkID}/{token}/"]
}

3. 重启 Docker：systemctl restart docker

4. 之后 docker pull nginx 自动走代理


GHCR 代理：

1. 创建类型为 ghcr 的链接

2. daemon.json 配置："registry-mirrors": ["https://yourdomain.com/{linkID}/{token}/"]

3. docker pull ghcr.io/owner/repo 自动走代理


GitHub 代理：

1. 创建类型为 github 的链接

2. curl -O https://yourdomain.com/{linkID}/{token}/github.com/user/repo/releases/...


鉴权模式说明：

• 双重鉴权：路径为 /{linkID}/{token}/，ID 用于标识，Token 用于验证

• 仅 Token：路径为 /{token}/，更简洁，适合个人使用
